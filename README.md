# IB DP Physics HL — Interactive Simulations

Nine self-contained simulations for Topic A (Space, Time and Motion), built to sit
alongside a set of DP Physics notes.

| Syllabus | Simulation | What it shows |
| --- | --- | --- |
| A.1.4 | `physics/graphs.html` | s–t, v–t and a–t linked, plus displacement vs distance |
| A.1.6 | `physics/projectile.html` | Independent components, drag comparison, energy trace |
| A.2.3 | `physics/buoyancy.html` | Archimedes, Stokes + form drag, terminal speed |
| A.2.5 | `physics/incline.html` | Static vs kinetic friction, limiting angle |
| A.2.8 | `physics/circular.html` | Vertical loop, conical pendulum, banked curve |
| A.2.10 | `physics/collisions.html` | Restitution, momentum and energy, centre of mass |
| A.4.2 | `physics/moments.html` | Principle of moments, solved balance point |
| A.4.6 | `physics/rolling.html` | Shape factor race down a slope |
| A.4.7 | `physics/angular.html` | L conserved while kinetic energy is not |

Each file is plain HTML, CSS and canvas JavaScript with no dependencies and no build step.
They work offline, follow the system light/dark theme, and embed cleanly in Notion.
